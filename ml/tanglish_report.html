Benchmark Basis & Methodology

  • Data — all 7,985 rows of data_tanglish_triage.csv from the Hugging Face dataset; fields: symptom_text (spoken-style Tamil/Tanglish/English) → risk_tier.
  • Tier mapping (dataset 4-tier → SwaraSetu IMCI 3-tier): ER_NOW → EMERGENCY_REFERRAL
  • CALL_ASHA → ASHA_DISPATCH
  • CLINIC_24H → ASHA_DISPATCH
  • HOME_CARE → SELF_CARE<
  • Pipeline — every row runs the production offline path: SarvamClient.extract_symptoms_rule_fallback(text, 'ta') → SymptomPayload → engine.evaluate(). No API key, no network, no LLM.
  • Defaults — dataset has no age column, so payloads use the engine default (age_group='child'); severity words (severe/romba/light/mild) are not yet extracted and therefore do not modulate risk.
  • Safety weighting — Critical Sensitivity 35% · Accuracy 25% · Macro-F1 20% · Under-triage avoidance 10% · Over-triage control 10%. Under-triage (missing an emergency) is the clinically dangerous direction and dominates error analysis above.
